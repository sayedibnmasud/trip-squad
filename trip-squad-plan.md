# Trip Squad — Project Plan

A group trip planner built on SELISE Blocks OS, as a learning project.

## The core idea

A group creates a trip, everyone suggests and votes on places, the AI turns the winners into a day-by-day itinerary, and the app tracks who paid for what so settling up afterwards is painless. A pocket phrasebook for the destination comes later.

## MVP features (version 1)

1. **Create a trip and invite friends.** Set a name, destination and dates, then share an invite link.
2. **Suggest and vote.** Anyone can add a place, food spot or activity. Everyone upvotes or downvotes.
3. **AI itinerary.** One button turns the top-voted suggestions into a sensible day-by-day plan, which the group can then tweak.
4. **Shared expenses.** Log "I paid 2,400 BDT for the boat," choose who it's split between, and see a running "who owes whom" balance.

### Version 2 (later)

- Destination phrasebook generated by AI
- Trip reminders ("Trip starts in 3 days, here's the plan")
- Photo sharing

## Data model (Data Gateway)

| Schema | Key fields |
|---|---|
| Trip | name, destination, startDate, endDate, memberIds, createdBy |
| Suggestion | tripId, title, type (place/food/activity), notes, addedBy |
| Vote | suggestionId, userId, value (+1/−1) |
| ItineraryDay | tripId, date, items (ordered list) |
| Expense | tripId, description, amount, currency, paidBy, splitBetween |

## Where each Blocks service comes in

- **IAM:** Sign-up and login. Each user has a profile with name and preferred language.
- **Data Gateway and RLS:** The most important learning piece. Write rules so a user can only read or write trips where their user ID is in `memberIds`, and the same for that trip's suggestions, votes and expenses. Test by logging in as an outsider and confirming you see nothing.
- **AI:** Generates the itinerary from the voted suggestions, dates and destination. In version 2, also generates the phrasebook.
- **Workflow:** Starts small. When an expense is added, recalculate balances. In version 2, add trip reminders.
- **Localization:** The app UI in English and Bangla from day one.

## Build order

1. Scaffold a Construct project (React or Blazor) and get login working.
2. Create the Trip schema and build a "My trips" page.
3. Add `memberIds` RLS and test it with two accounts.
4. Add suggestions and voting.
5. Add expenses and the balance calculation.
6. Add the AI itinerary button.
7. Localize the UI.

Steps 1 to 3 are the foundation. Once membership security works, everything else is adding features on top.
